iPix Beginner Guide

从安装到第一张改图、第一段视频。

这份教程面向第一次使用 iPix 的普通用户。按顺序完成安装、GetToken 接入、Qwen 文生图与参考图改图，再用 Seedance 2.0 生成视频。

下载 iPix 开始上手
01 / Install

下载当前双平台测试版。

当前版本是 v0.21.0-gettoken.7，支持 Apple Silicon Mac、macOS 12.0+ Intel Mac 与 Windows x64。普通用户不需要 Docker、数据库或命令行。

Mac Apple Silicon

适用于 macOS 12+ 的 M1 / M2 / M3 / M4。安装后应用名为 iPix Preview。

下载 DMG

Mac Intel x64

适用于 macOS 12.0+ 的 Intel i5 / i7 / i9 Mac。

下载 Intel DMG

Windows x64

适用于 Windows 10 / 11，64 位。

下载 EXE

完整发布页

查看更新说明、文件大小与 SHA-256 摘要。

打开 Release
从旧版升级

先退出并删除旧的 Nomi Preview，再安装 iPix Preview。设置、凭据和项目目录会继续兼容。

02 / First Project

新建一个空白项目。

打开 iPix，点击“新建空白项目”。已有素材时也可以直接选择“打开已有文件夹”。

03 / GetToken

接入 GetToken。

进入“设置 → 模型 → 自定义 API / 中转站”。Base URL 必须填写 https://www.gettoken.net，再粘贴自己的 API Key。

1

填写连接

名称填 GetToken，Base URL 填 https://www.gettoken.net，鉴权选择 Bearer/API Key。

2

添加图像模型

文生图添加 qwen-image-2.0；参考图改图添加 qwen-image-2.0-pro。

3

添加视频模型

从账户模型列表选择 Seedance 2.0。模型名以 GetToken 当时返回的列表为准。

4

准备文本模型

要用 AI 助手写故事或拆镜头，还需要至少一个可用文本模型。

04 / First Image

生成第一张图片。

打开项目顶部“生成”，添加图片节点，选择“文生图”。第一次使用建议 1:1、1K、1 张，先把完整闭环跑通。

操作顺序

  1. 添加图片节点。
  2. 选择 Qwen Image 2.0 或 Pro。
  3. 设置 1:1、1K、生成 1 张。
  4. 输入提示词并生成。
  5. 到右上角“任务”查看进度。

可直接使用的提示词

一只透明绿色玻璃花瓶放在白色木桌上，柔和自然侧光，干净的产品摄影，背景简洁，真实材质，方形构图。

05 / Reference Edit

用 Qwen Pro 参考图改图。

切换到“改图”，把本地图片拖入输入图区域，模型选择 Qwen Image 2.0 Pro。提示词要同时说明哪些内容保持不变、哪些内容需要改变。

改图提示词示例

保留人物、服装、姿势和原有构图，只把背景改成傍晚的海边，天空呈柔和粉色，光线方向与人物一致，保持写实摄影质感。

06 / Seedance 2.0

生成第一段视频。

添加视频节点。没有图片时选“文生视频”；已有满意图片时，把图片连接到视频节点并选择“图生视频”。第一次建议 5 秒、720p。

文生视频

  1. 选择 GetToken 的 Seedance 2.0。
  2. 设置 5 秒、720p 和所需比例。
  3. 提示词写主体动作、镜头运动、环境变化。
  4. 提交后从“任务”查看轮询状态。

图生视频

  1. 连接图片作为首帧/参考图。
  2. 提示词主要写运动，不要重复堆外观词。
  3. 人物一致性来自参考图，镜头变化来自动作描述。
  4. 任务未结束前不要重复提交。
视频提示词示例

镜头缓慢向前推进，女孩站在海边轻轻回头，头发被微风吹动，远处海浪自然起伏，电影感自然光，人物身份和服装保持稳定。

07 / Timeline

放入时间轴并导出。

选择满意的视频结果加入时间轴，拖动片段调整顺序，预览完整播放一次，然后导出 MP4。

08 / Troubleshooting

卡住时先检查这些。

任务失败通常来自地址、余额、模型类型或上游状态。先看任务中心给出的真实错误，不要连续重复提交。

连接显示不可用

确认 Base URL 是 https://www.gettoken.net，Key 没有多余空格，并检查账户余额。

Qwen 改图提示尺寸错误

升级到 v0.21.0-gettoken.7。该版本会把 1:1 + 1K 转成上游要求的像素尺寸。

成功但没有图片

重启 iPix 让启动修复更新旧 Qwen Pro 映射，再提交一次新任务。

Seedance 一直排队

保持 iPix 运行并查看任务中心；长时间无进展时再到 GetToken 后台核对任务和余额。

AI 助手不能拆镜头

确认至少接入一个文本模型。图片或视频模型不能充当文本大脑。

保护自己的 Key

不要把完整 Key、签名素材 URL 或供应商任务 ID 发到群聊和截图中。
